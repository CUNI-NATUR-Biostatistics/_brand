# Biostatistika course logo

This directory is the canonical source for the Biostatistika (MB120P163) course logo. The mark combines ecological context (the leaf), observed data (the bars), and statistical reasoning (the rising fitted line).

## Files

| File | Intended use |
| --- | --- |
| `biostatistika-icon.svg` / `.png` | Default full-colour icon on white, cream, or another quiet light background |
| `biostatistika-icon-monochrome.svg` / `.png` | One-colour reproduction when the course palette is unavailable |
| `biostatistika-icon-reversed.svg` / `.png` | Navigation bars, dark backgrounds, and other compact reversed uses |
| `biostatistika-logo-horizontal.svg` / `.png` | Wide headers, website mastheads, and landscape documents |
| `biostatistika-logo-vertical.svg` / `.png` | Narrow layouts, title pages, and portrait documents |
| `source/approved-logo-board.png` | Approved design board retained as the visual provenance record for Issue #4 |

SVG files are the editable masters traced directly from the approved board artwork. PNG files are web and office-document exports generated from those masters at their native dimensions. The paths preserve the geometry, proportions, and lettering of the approved artwork. Small raster specks, antialiasing halos, and jagged edges were removed during vector cleanup; the source board remains the reference for any further refinement.

## Usage rules

- Preserve clear space around the mark equal to at least the diameter of one gold data point.
- Do not display the icon below 15 mm in print or 120 px on screen unless it is used as a browser favicon or navigation mark.
- Use the full-colour files on white, cream, or quiet light neutral backgrounds; use the reversed file on deep purple or dark photographic backgrounds; use monochrome only when colour reproduction is unavailable.
- Do not recolour, distort, rotate, crop, separate, or rearrange the components.
- Do not place the full-colour mark on gold, saturated green, or another background that reduces contrast.

The logo uses the canonical course colours from `quarto/colors.json`. Lockup text uses Source Sans 3 with Arial-compatible fallbacks.
